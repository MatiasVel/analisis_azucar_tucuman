Fuentes primarias

Precio de mercado + índice de precios

El estudio cruza la cotización diaria de la bolsa de azúcar con el IPC. Ninguna de las dos fuentes alcanza por sí sola: la primera mide el mercado, la segunda permite comparar pesos de distintas épocas.

Fuente 1 · Mercado

Centro de Agricultores Cañeros de Tucumán (CACTU)

Entidad gremial de los productores cañeros de Tucumán. Provee la serie histórica de cotizaciones de la bolsa de azúcar en el mercado interno, utilizada como referencia por el sector.

Contexto sectorial

EEAOC

La Estación Experimental Agroindustrial Obispo Colombres produce información técnica sobre la caña de azúcar y la actividad sucroalcoholera de Tucumán (estimaciones de cosecha, molienda y rendimientos). Citada en el paper como referencia [4].

Contexto sectorial

IPAAT

El Instituto de Promoción del Azúcar y Alcohol de Tucumán es el organismo provincial de aplicación del régimen sucroalcoholero y realiza el seguimiento semanal de la zafra (caña molida, azúcar y alcohol producidos). Citado como referencia [5].

Por qué no el dólar

Dólar informal: descartado

La cotización del dólar blue incorpora brechas cambiarias, controles de capitales e inflación propia de la divisa. Usarla como deflactor introduciría ruido ajeno al mercado doméstico del azúcar. Ver comparación

Qué tan completa es la serie diaria

Antes de modelar se verificó la integridad de los datos. La serie diaria registra precio todos los días de la semana —incluidos sábados y domingos—, por lo que la cobertura se mide sobre días calendario.

Registros por año

2026: hasta el 11 de septiembre

Lo que hay que saber

  • Huecos detectados: del 20 al 31 de enero de 2009 (12 días) y del 1 al 20 de febrero de 2019 (20 días), más seis días aislados en 2018–2020. Los promedios de esos meses se calcularon con los días disponibles.
  • Extremos nominales: mínimo de $ 55,00 el 27/11/2008 y máximo de $ 37.165,00 el 18/06/2026.
  • Septiembre de 2026: el archivo diario llega al 11/09/2026, pero ese mes queda fuera del análisis por estar incompleto y no tener aún coeficiente IPC (la unión con el deflactor es interna).
  • Valores no numéricos: símbolos monetarios, separadores de miles y leyendas como «s/c» se eliminaron en la extracción.

Reproducibilidad

Cada cifra se puede regenerar

El repositorio incluye el pipeline completo. Al ejecutarlo se recalculan la serie real, el filtro HP, la Tabla 1, las pruebas complementarias, las figuras 4K y los datos de este sitio.

  • Entorno original: Python 3.13 · Jupyter Notebook en Visual Studio Code.
  • Librerías: Pandas, NumPy, Statsmodels y Matplotlib; SciPy y scikit-learn para la validación y el prototipo predictivo.
  • Verificación: si statsmodels está instalado, el pipeline comprueba que su hpfilter y la implementación matricial propia den el mismo resultado.
# 1. Obtener el proyecto
git clone https://github.com/MatiasVel/analisis_azucar_tucuman.git
cd analisis_azucar_tucuman

# 2. Instalar dependencias
pip install -r analysis/requirements.txt

# 3. Recalcular datos, Tabla 1 y validación
python analysis/pipeline.py

# 4. Regenerar las figuras 4K y las fórmulas
python analysis/figuras.py

# 5. Prueba de concepto de machine learning
python analysis/prototipo_ml.py

# 6. Ver el sitio en local
python -m http.server --directory site 8000
